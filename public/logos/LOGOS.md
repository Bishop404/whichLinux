# Logo policy and notices

Only explicitly approved source assets are shipped. All other distribution names
are intentionally displayed as text until their trademark and asset terms have
been verified. The application loads these files as images and never recolours
or rewrites their SVG markup.

Two rules decide whether a mark can be shipped:

1. **The file comes from the project that owns the mark**, not from a third-party
   icon collection or a re-upload. A downstream asserting a licence over someone
   else's logo is not a grant.
2. **That project published terms that permit redistribution.** Where a project
   ships its own artwork under a free licence, that licence is the grant; where
   it publishes brand guidelines instead, those govern. Silence is not permission.

Each asset below is stored byte-identical to its source, pinned to the commit it
was taken from.

## Deliberately not shipped

| Distro | Why |
| --- | --- |
| `mint` | [linuxmint/brand-logo](https://github.com/linuxmint/brand-logo) is the official brand repository but states no licence. |
| `mx` | Simple Icons records GPL-3.0-only, sourced from <https://mxlinux.org/art/>, but that page is not reachable for verification. Worth rechecking by hand. |
| `manjaro` | Only `manjaro-contrib` community artwork repositories, none licensed. |
| `nobara` | No branding or artwork repository under `Nobara-Project` carries a licence. |
| `kubuntu`, `ubuntu-studio` | No published artwork repository or asset terms found. |
| `lubuntu` | [lubuntu-team/artwork](https://github.com/lubuntu-team/artwork) is GPL-2.0, but ships only a 252×97 white-on-transparent wordmark for a boot splash — unusable on a light chip. A vector mark under those terms would qualify. |
| `zorin` | Press page only; no redistribution terms. |
| `fedora` | The Fedora Council grants permission to include the official logo in an icon collection, unmodified except in size or file format, on condition that a specific trademark notice and a link to the brand guidelines are reproduced. The official vector file is not a public download — it is obtained by request from `logo@fedoraproject.org`. Doable, but it needs that request and the notice, so it has not been assumed. |
