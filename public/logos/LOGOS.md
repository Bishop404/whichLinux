# Logo provenance and licensing

Every logo in this directory is the real mark of the project it identifies. This
file records where each one came from and under what terms, so the obligations
can be checked rather than assumed.

## Two separate questions

**Copyright** governs copying the image file. **Trademark** governs using the
mark in a way that could confuse people about who endorses what. A file can be
freely licensed and still be a trademark — most of these are.

This site's use is *nominative*: the logos identify the actual products being
recommended, at small size, unaltered, next to the project's own name and a link
to its official site. It does not use any mark in its own name, domain, branding
or favicon, and states plainly that it is not affiliated with or endorsed by any
of these projects. That disclaimer is shown to visitors on the results page.

upstream source is listed per row). Where Simple Icons declares a specific

Each glyph is filled with the brand's own official colour as published by the

## Obligations that actually apply

- **Debian** (`debian.svg`) — CC BY-SA 3.0. Attribution above; the file is
  unmodified apart from being filled with Debian's own brand colour. Debian is a
  registered trademark of Software in the Public Interest, Inc.
- **MX Linux** (`mx.svg`) — GPL-3.0-only. The SVG here *is* the source form, so
  distributing it satisfies the source requirement; this notice is the licence
  notice.
- **Fedora** (`fedora.svg`) — governed by the
  [Fedora brand guidelines](https://docs.fedoraproject.org/en-US/project/brand/),
  not a standard open licence. Fedora is a trademark of Red Hat, Inc.
- **Omarchy** (`omarchy.svg`) — MIT.
- **Bazzite** (`bazzite.svg`) — Apache-2.0, taken from the project's own press
  kit and used **unmodified**, as that press kit requires: "Please do not distort
  or modify the artwork or logos, including spacing, color, elements, and
  scaling." It is therefore the one full-colour logo in the set.
- **Ubuntu / Kubuntu / Ubuntu Server / Ubuntu Studio** — UBUNTU and KUBUNTU are
  trademarks of Canonical Ltd. Canonical's policy requires permission for use in
  a domain name, for merchandising, or for any mark confusingly similar to
  theirs. None of those apply here. Referring to the products by name and mark
  does not.

## If you would rather not rely on this

The safest alternative is to drop the images and show project names as text
only. Nothing in the application depends on the logos rendering — a missing file
degrades to an empty chip.

## Re-generating

The Simple Icons files are produced from the `simple-icons` dev dependency and
each distro's `logo` field in `src/data/distros.json`. Bazzite and Ubuntu Studio
are downloaded from the sources above and are not generated.
