# Logos

These are **placeholder lettermarks**, not the real project logos.

Distribution logos are trademarks. Before this site goes public, replace each file
with the official SVG from that project's own brand or press page, keep the
filename, and check each project's trademark policy — most permit factual,
editorial use of this kind, but the terms differ and a few ask for attribution.

Filenames must match the `logo` field in `src/data/distros.json`.
